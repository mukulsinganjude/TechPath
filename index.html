06 · COMPUTER SCIENCE VISUALIZER

See algorithms in action.

Algorithms are repeatable steps for solving a problem. Visualising each comparison or swap helps connect code to behaviour. This local demo sorts a small list using bubble sort; its \(O(n²)\) worst-case growth makes it useful for learning, not for large datasets.

Press Next step to compare adjacent values.

Complexity quick guide

O(1) constant · O(log n) halves the search space · O(n) visits each item · O(n log n) common efficient sorting · O(n²) nested pairwise work.
